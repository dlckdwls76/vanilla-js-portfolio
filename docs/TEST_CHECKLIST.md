## 오류 상태 재현

빈 목록이나 403을 만들려고 저장소를 삭제하거나 API 제한을 소진하지 마세요. 개발자 도구의 로컬 응답 재정의(Overrides) 또는 테스트용 요청 가로채기로 빈 배열과 오류를 재현할 수 있습니다. 끝나면 요청 차단과 재정의를 해제합니다.

자동 검증에서는 실제 API 응답을 한 번 받아 재사용하고 빈 배열·403·500·통신 실패·잘못된 데이터·지연 응답을 따로 주입했습니다. 모의 응답은 서비스 코드와 배포 데이터에 포함하지 않았습니다.

## 초기 검증 기록 · 2026-09-08

환경: 로컬 HTTP 서버와 설치된 Chrome의 자동 브라우저 실행. 도구는 실행 환경에서만 사용하며 웹사이트에는 라이브러리를 추가하지 않았습니다. 사용자 본인의 학습 완료 기록을 의미하지 않습니다.

- 실제 API 응답 및 카드 생성
- 테마 전환 및 새로고침 유지
- 빈 값·공백·이메일 검증, 첫 오류 초점, 성공 후 수정
- 60px 탐색 배경, 300px 맨 위 버튼, 최상단 이동
- 모바일 메뉴, Escape, 앵커 선택
- 320 / 390 / 768 / 1024 / 1440px 가로 넘침
- 로딩·빈 목록·403·500·통신 오류·잘못된 데이터·재시도·10초 초과
- 외부 HTML 문자열이 실행되지 않고 텍스트로 표시되는지 확인
- 저장 접근 차단, 모션 감소 환경
- JavaScript 구문 검사, 런타임 오류, 인라인 style·onclick 금지 확인
- 실제 응답을 재사용한 [스크린샷 3종](screenshots/)
